# Martian Academy Homebrew Tap

Official Homebrew tap for [Olympus Coder](https://github.com/martianacademy/olympus-coder).

## Install Olympus Coder (macOS Apple Silicon)

```bash
brew install --cask martianacademy/tap/olympus-coder
```

## Upgrade

```bash
brew upgrade --cask martianacademy/tap/olympus-coder
```

## Uninstall

```bash
brew uninstall --cask martianacademy/tap/olympus-coder
```
